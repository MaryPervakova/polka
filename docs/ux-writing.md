Дата: 24 ноября 2026 года. Статус: терминология из исходных требований и проекты ещё не согласованных сообщений.

«Ответственный» — лид; «Исполнители» — участники работ; «Заказчик» — отдельное текстовое поле. Не объединять эти понятия. «Последние изменения» относятся к странице; системное время относится к карточке. «Черновик» не означает только незаполненную карточку.

Имена полей и форматы: [data-model.md](data-model.md). Полный смысл статусов: BR-05. Тег «Стандартный блоки» сохраняется буквально до нового решения; редакционное исправление имени не вводится автоматически.

## Проекты сообщений

Следующие тексты предложены для дальнейшего UX-согласования. Смысл ограничений уже подтверждён, точная редакция — нет.

| Ситуация | Проект текста |
| --- | --- |
| Уход с правками | У вас есть несохранённые изменения. Выйти без сохранения? |
| Найден дубль в каталоге | Эта страница Tilda уже есть в каталоге. Откройте существующую карточку. |
| Найден дубль в корзине | Эта страница Tilda находится в корзине. Можно восстановить существующую карточку. |
| Конфликт | Карточку изменил другой сотрудник. Ваши изменения не сохранены. |
| Будущая дата изменений | Укажите сегодняшнюю или прошедшую дату. |
| Неподходящий файл | Выберите PNG, JPG или WebP размером до 5 МБ. |
| Окончательное удаление | Карточку нельзя будет восстановить. |
| Пояснение к пустому результату | Попробуйте изменить запрос или фильтры. Основной текст «Ничего не найдено» утверждён |
| Ошибка сохранения | Не удалось сохранить карточку. Попробуйте ещё раз. |

При конфликте утверждены сохранение введённого в форме и отдельное открытие актуальной версии; точная редакция предупреждения остаётся проектом. Не обещать в тексте ещё не реализованные возможности. Сообщения об обязательности полей и пары даты/описания не используются: все поля можно заполнять независимо и дополнять позже.

## Предлагаемые правила редакции

Писать по-русски, коротко называть причину и доступное действие. Подтверждение безвозвратного удаления должно сообщать о невозможности восстановления. Не называть удаление карточки удалением внешнего сайта. Не показывать отметку «Не хватает данных» у старых карточек.

Открыто: окончательные тексты ошибок формата заполненных значений, поиска, загрузки превью, доступа и предупреждения о конфликте. Содержимое этого раздела не вводит новые проверки полей.
